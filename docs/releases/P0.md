# P0 — Engineering Foundation

## Delivered

- npm workspaces: explorer, shared, catalog, simulation, renderer, cinematic.
- English responsive app shell with direct WebGL Sun/Earth/Moon preview, manual camera controls, pause/resume, reset and WebGL failure message.
- Explicit illustrative data and elapsed-time simulation boundary.
- Renderer cleanup, DPR cap, resize handling and seeded decorative stars.
- Strict TypeScript, clock tests, pinned dependencies and lockfile.
- GitHub Actions check/build workflow and PR template.
- Architecture decisions, scientific conventions, roadmap and future pipeline boundaries.
- Original HTML archived unchanged outside the application build; its Bangla text appears only in that reference.

## Validation performed

- `npm run check`: passed (type check, three clock tests, production build).
- Lockfile consistency: `npm ci --offline --ignore-scripts --no-audit --no-fund --dry-run` passed.
- Build smoke: English HTML entry, linked script/style assets exist, reference excluded, app source contains no Bangla text.
- Build: 34 modules; app ~6.9 kB, React ~186 kB, Three.js ~518 kB before gzip.

## Known limits

No local browser binary was available, so interactive WebGL and mobile visual QA were not run here. CI is configured; check the PR for its remote result. Scientific accuracy, full catalog, cinematic runtime and export belong to future phases. Deployment and branch protection are not configured.

The Three.js vendor chunk triggers Vite's 500 kB advisory. Vendor chunks are separated for caching. Rollup tree shaking is disabled in P0 because the initial build consumed excessive resources; minification remains enabled. Revisit fine-grained imports and tree shaking during performance qualification. No device FPS target is claimed.
