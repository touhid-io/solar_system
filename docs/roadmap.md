# Execution roadmap

| Phase | Deliverable |
|---|---|
| P0 | Engineering foundation and English preview |
| P1 | Scientific data contract and validated source manifests |
| P2 | Time, orbital and orientation core |
| P3 | Sun and all eight planets, explorer navigation |
| P4 | Versioned complete known natural satellite catalog |
| P5 | Professional textures, atmospheres, rings and lighting |
| P6 | Validated date-based ephemeris mode |
| P7 | Responsive professional explorer UX |
| P8 | Camera timeline and cinematic sequences |
| P9 | Deterministic production video export |
| P10 | Dwarf planets, selected small bodies and belt representations |
| P11 | Integrated release qualification |

Each phase requires documented completion checks. Catalog completeness is relative to a named dataset release. P0 does not freeze later numerical algorithms or promise realtime 4K rendering on every device.
